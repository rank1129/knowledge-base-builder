# {行业} 知识库

> 本知识库由渐进式访谈萃取生成。模块标注说明：
> `待采集` = 尚未收集；`待萃取` = 有信息但未提炼成规律；`推测` = 基于已有信息推演，需验证。

## 00 使用说明

- 本库共 19 个模块，按优先级分为 P0（核心）/ P1（重要）/ P2（增强）/ P3（数据）
- 补充新素材时，直接追加到对应模块，并更新 `updated` 字段
- 模块 1「行业判断标准」是全库核心，其余模块是它的具体展开

## 01 行业判断标准（P0）

> 对内容/业务的理解与判断力。参考 15 条方法论逐条填写，不确定的留空待补。

1. 客户视角代入（圈层 / 关系 / 一天 / 情绪 / 事件 / 通用焦虑 / 行业黑话）
2. 预判拒绝理由并在素材中解决
3. 深层动机挖掘
4. 购买场景逐帧模拟
5. 爆款框架
6. 获客类型覆盖（场景 / 身份认同 / 日常性疼痛 / 专家经验呈现 / 开头钩子 / 画饼）
7. 亲和感与对话感
8. 直接结果与案例反馈
9. 行业理解与客户视角真心话
10. 承认不完美 / 暴露无关紧要的瑕疵
11. 互动感
12. 从「我的产品」切换到「她的场景」
13. 拓宽产品边界
14. 让用户替你开口
15. 巧用热点
