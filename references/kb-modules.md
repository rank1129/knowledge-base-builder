# 知识库 19 项模块定义

知识库由 19 个模块构成。访谈收集与最终输出都以这 19 项为骨架。每项标注优先级，用于决定「缺失时是追问补齐还是留空标注」。

## 优先级总表

| 级别 | 含义 | 模块 |
|------|------|------|
| P0 | 核心，缺失则知识库不成立，必须追问补齐 | 1、7、11、17 |
| P1 | 重要，直接影响可用性，尽量补齐 | 2、5、9、10、12 |
| P2 | 增强，有则更好，无则留空标注待采集 | 3、4、6、8、13、14、15、16 |
| P3 | 数据类，通常需工具采集，可后期补充 | 18、19 |

---

## 模块 1：行业判断标准（P0）

**定义**：对内容/业务有理解和判断的能力标准。这是整个知识库最核心的资产——它不是信息，是判断力。

**收集要点**：从访谈中提炼用户「凭什么判断这条内容会火 / 这个客户会买」的隐性标准。

**参考框架（15 条方法论，判断知识库是否达标）**：

1. 不管是谁，要吸引别人买单，先代入对方视角模拟其圈层、可能拥有的关系、可能的一天、可能接触的人、可能诱发的情绪、可能发生的事件，以及该人群通用焦虑（习惯性疼痛）、行业黑话
2. 想到别人可能拒绝你的理由，并呈现在素材中，然后解决它
3. 挖掘人群深层动机——买东西不只是物品实际作用，可能是对生活缺乏掌控欲、这一刻她被看见了、或对童年自己的补偿，有千万种理由
4. 购买场景模拟：她会产生的动作，从最初找这个东西的由头、渠道开始，一个念头导致下一个动作，直到成交和反馈聊天，每一帧都可作为内容素材与获客素材——核心是把握人的心理
5. 爆款框架——最简单、最容易学，门槛最低
6. 获客无非几大类：场景 / 身份认同 / 日常性疼痛 / 行业价值和专家经验的呈现方式 / 开头差异拉停留（钩子、结构、解决不想买的理由）/ 画饼（预设得到后的生活方式提升）
7. 亲和感——姐妹贴近生活实际的语气与对话感风格
8. 直接结果和别人的案例反馈
9. 自己对行业的理解，站在客户视角的真心话
10. 承认不完美——故意暴露无关紧要的瑕疵，与用户关心的产品点关联不大，如「就是物流有点久」，或通过瑕疵反差化自己的好
11. 互动感，多和用户互动、回复评论
12. 很多时候我们是在替用户解释「你为什么购买我的东西」，而不是站在用户场景说「这个东西如何在我的生活场景中，解决我需要面向的人的场景」
13. 想用户所想不到，拓宽产品边界——如煲仔饭的炉子还能做围炉煮茶的底，功能性大于正常价值
14. 要让用户替你开口
15. 巧用热点，把近期热点结合进文案提一嘴，万物为我所用，融入而非硬套

**延伸认知（可作为模块备注）**：把能力发挥到极致的压榨方法论是「一波素材多用」——同样素材公私域混用，根据不同受众的不同需求用不同形式呈现，本质是一鱼多吃。看到很多人找你，用户会觉得你难约、靠谱；老板看到你这么多私信，会觉得你获客能力牛。这就是根据受众设计内容的心理思路与好处。

## 模块 2：文案基础标准（P1）

详见 `copywriting-standards.md`。核心是摆脱 AI 腔与官方通稿：把受众当闺蜜，用感官和细节描述，从「我」出发，暴露真实弱点。

## 模块 3：爆款案例（P2）

收集真实爆款样本：链接/截图描述 + 标题 + 首图类型 + 数据表现 + 为什么火（拆解判断）。

## 模块 4：真实评论（P2）

收集评论区真实用户原话。热评就是选题，用户的原话就是最好的文案素材。

## 模块 5：写作风格标准（P1）

详见 `copywriting-standards.md`。含语气、字数、表情符号规范、防同质化规则。

## 模块 6：硬性要求（P2）

字数、格式、排版、发布节奏等硬性约束。例如「950 字左右」「表情+符号，不带标签」。

## 模块 7：获客底层方法论和框架（P0）

从访谈 Phase A/B 萃取的获客逻辑：什么内容带来什么人、钩子的设计原理、公私域衔接方式。

## 模块 8：文案心理小技巧（P2）

具体可复用的心理技巧：损失厌恶、身份认同、稀缺制造、社会证明、统一敌人等。

## 模块 9：评论区该人群表层痛点（P1）

用户自己说出来的痛点（表层）。来源是评论区、私信、成交前问得最多的问题。

## 模块 10：此类人群深层需求（P1）

表层痛点之下的真实动机。判断标准：表层是「我想要什么」，深层是「我想成为什么 / 想被谁看见 / 想摆脱什么」。

## 模块 11：人群受众（P0）

完整人群画像：年龄段、职业身份、家庭身份、社交圈层、日常动线、日常性疼痛、深层动机。对应 Phase A1 产出。

## 模块 12：爆款标题（P1）

标题公式库。收集已验证有效的标题格式，按类型归类（数字型 / 痛点型 / 身份型 / 反常识型 / 场景型）。

## 模块 13：行业近期热点和全平台热梗（P2）

时效性内容，标注采集日期，便于后续更新。

## 模块 14：tag（P2）

话题标签库：行业大词 + 精准长尾 + 热点词，分类管理。

## 模块 15：同行话术（P2）

三类：导流话术 / 评论回复话术 / 钩子话术。收集同行与自己的，标注效果。

## 模块 16：平台规则（P2）

违禁词、违禁类目、平台规则、社区公约要点、已踩过的坑。

## 模块 17：消费者购买路径（P0）

从契机到下单的完整链路还原，每一帧标注「此处可做什么动作」。对应 Phase A2 产出。

## 模块 18：平台各大关键词数据（P3）

关键词搜索量、竞争度等数据。通常需借助数据工具采集，标注数据来源与采集日期。

## 模块 19：衍生关键词（P3）

由核心关键词衍生出的长尾词，用于选题拓展。

---

## 判断标准：模块是否算「已收集」

- **达标**：有具体判断或可复用规律，不是空泛描述
- **部分**：有信息但未提炼成规律，需标注「待萃取」
- **缺失**：无内容，标注「待采集」

整合阶段逐项标注，交付时向用户展示完成度概览。
